# FlyTicket - Flight Booking System

## [cite_start]Technologies Used [cite: 68]
* [cite_start]**Frontend:** React, Tailwind CSS [cite: 11]
* [cite_start]**Backend:** Node.js, Express.js [cite: 12]
* [cite_start]**Database:** MySQL [cite: 13]

## Database Setup
* [cite_start]An exported database file (`[veritabani_adin].sql`) is included in the root directory.
* Import this file into your SQL server.
* Create a `.env` file in the backend directory based on the database connection variables and email credentials.

## [cite_start]How to Run the Project [cite: 66]

### Backend
1. Open a terminal and navigate to the backend folder: `cd backend`
2. Install the necessary packages: `npm install`
3. Start the backend server: `npm start` 

### Frontend
1. Open a new terminal and navigate to the frontend folder: `cd frontend`
2. Install the necessary packages: `npm install`
3. Start the React application: `npm start`
